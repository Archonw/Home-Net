# Plan

Home-Net wird ein Baukasten für jedes Linux mit Docker. Die Schritte:

1. Rücksicherung prüfen: erledigt
2. Bestand absichern: erledigt
3. Repos zusammenführen: erledigt
4. Baustein-Beschreibung je Modul: erledigt
5. Pi-Wartung-Sicherung im Container: erledigt
6. Gemeinsamer Zugang: gebaut
7. Installationsprogramm: gebaut
8. Weboberfläche: gebaut

Für das Unraid gibt es `tools/migrate-unraid.sh`. Danach ersetzt die Weboberfläche die alte PC-App.
